# Genetic Algorithm Parameters

В `Planning Service` генетический алгоритм реализован на библиотеке `DEAP` в файле [genetic.py](C:/Users/vladd/Desktop/magistral/planning/app/genetic.py). Ниже зафиксированы текущие рабочие параметры.

## Основные параметры

- `seed = 42`  
  Фиксирует генератор случайных чисел, чтобы результаты были воспроизводимыми между одинаковыми запусками.

- `population_size = 80`  
  Размер популяции в одном поколении. Чем больше значение, тем шире поиск, но тем выше стоимость расчета.

- `generations = 40`  
  Количество поколений эволюции. Определяет, сколько итераций алгоритм делает перед выбором лучшего решения.

- `cxpb = 0.7`  
  Вероятность crossover на шаге эволюции. В текущей конфигурации 70% особей участвуют в скрещивании.

- `mutpb = 0.25`  
  Вероятность mutation для особи. Используется на уровне индивида внутри `eaSimple`.

- `indpb = 0.2`  
  Вероятность мутации конкретного гена внутри особи. Для каждого студента отдельно могут измениться слот, инструктор и автомобиль.

- `tournsize = 3`  
  Размер турнира в `selTournament`. Из трех кандидатов выбирается лучший для дальнейшей эволюции.

- `HallOfFame(1)`  
  Сохраняется одна лучшая особь за весь прогон алгоритма.

## Структура особи

Одна особь хранит по `3` гена на каждого ученика:

- `slot_index`
- `instructor_index`
- `car_index`

Если `slot_index = -1`, ученик считается нераспределенным.

## Fitness

Целевая функция вычисляется через `score_plan(...)`.

Она оценивает:

- сколько учеников удалось запланировать
- есть ли конфликты по студенту, инструктору и автомобилю
- есть ли пересечения с уже существующими занятиями
- итоговое качество расписания

## Текущая логика операторов

- `crossover`: `tools.cxTwoPoint`
- `selection`: `tools.selTournament`
- `mutation`: кастомная `_mutate_individual(...)`
- основной цикл эволюции: `algorithms.eaSimple(...)`

## Практический смысл текущих значений

Текущая конфигурация выбрана как компромисс между качеством и скоростью:

- популяция `80` дает достаточно вариантов для поиска
- `40` поколений хватает для базовой оптимизации без сильного роста времени ответа
- `0.7` на crossover и `0.25` на mutation дают баланс между стабильностью и исследованием новых комбинаций
- `0.2` на уровне гена позволяет вносить локальные изменения без полного разрушения удачных решений
